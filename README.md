# zizAI

[中文](#中文) · [日本語](#日本語) · [English](#english)

## 中文

zizAI 是一款面向中日双语用户的智能输入法，支持中文与日文自然混输，无需手动切换语种，并通过 AI 候选重排，让选词更准确、输入更流畅。

## 日本語

zizAI は、中国語と日本語を使うユーザー向けのスマートな入力ソフトです。言語を手動で切り替えずに両言語を自然に混ぜて入力でき、AI による変換候補の並べ替えで、より的確な候補選択とスムーズな入力を支援します。

## English

zizAI is an intelligent input method for users who write in Chinese and Japanese. It lets you mix Chinese and Japanese naturally without manually switching languages, and uses AI to rerank candidates for more accurate selection and a smoother typing experience.
